# Silent Strokes

A clean, faster, more production-ready portfolio for the Silent Strokes project.

## Included

- improved landing page layout and messaging
- cleaner static structure with dedicated CSS and JS assets
- SEO metadata and sitemap support
- better responsive behavior and mobile navigation
- safer Supabase config placeholders for the Studio app

## Files

- `index.html` — public portfolio landing page
- `studio.html` — private creator studio interface
- `assets/css/styles.css` — portfolio styling
- `assets/js/main.js` — simple UI interactions
- `supabase-config.js` — configuration template with placeholders only
- `robots.txt` — search indexing instructions
- `sitemap.xml` — sitemap for the public portfolio

## Notes

The Studio app should still be configured with real Supabase values in a secure environment before deployment. Do not commit production secrets to a public repository.
